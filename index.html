01 · About

From the server room to the full stack

I started my career as a Server Administrator and IT Manager, running Linux and Windows servers, LAMP stacks, firewalls and security audits. That background still shapes how I build software today: I think about what happens after deploy, not only before it.

I've spent 4+ years as a full stack developer, including 3 years 10 months as a Senior Software Developer at Zasya Solutions, where I led Everlast, a multi-channel e-commerce and inventory platform syncing Amazon, eBay, Drupal and custom stores. Most of my projects start from a blank repo: I gather requirements, design the database and APIs, build the frontend, wire up payment and communication integrations, and ship to AWS.

I'm usually the person who gets pulled in when something breaks in production, whether the cause is in the code, the database, the server or the network.
